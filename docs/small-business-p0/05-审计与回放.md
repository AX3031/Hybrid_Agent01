# 05 审计与回放（P0-6）

## 1. 审计要回答的三个问题

不是“记录一切”，而是事后能回答：

1. **发生了什么**：哪个工具、什么参数、结果如何；
2. **谁批准的**：是 Agent 自己调用，还是人工点了确认、输入了 PIN；
3. **在哪个任务/批次里**：这次操作属于哪张任务卡、哪个批次号、第几步。

## 2. 审计记录长什么样

文件：`logs/audit_YYYYMMDD.jsonl`，一行一条 JSON。

工具调用示例（字段已简化）：

```json
{
  "time": "2026-10-27T11:08:05",
  "event": "tool_call",
  "trace_id": "a1b2c3d4e5f6",
  "task_id": "a1b2c3d4e5f6",
  "batch_id": "B20261027-110805-a1b2",
  "step_no": 3,
  "session_id": "user_001",
  "tool": "write_text_file",
  "args": {"path": "D:\\归档\\2026\\a.txt", "mode": "write"},
  "status": "success",
  "reversibility": "R1",
  "approver": "human",
  "approval_token": "……",
  "result": "已写入..."
}
```

关键字段：

| 字段 | 含义 |
| --- | --- |
| `trace_id` / `task_id` | 本次任务；贯穿任务开始、工具调用、结束 |
| `batch_id` | 本次任务的改动批次，可用于整批回滚 |
| `step_no` | 第几步工具调用 |
| `reversibility` | R0 只读 / R1 可撤销 / R2 难逆 / R3 不可逆 |
| `approver` | `agent`（直接执行）或 `human`（人工批准） |
| `approval_token` | HMAC 签名凭证；不包含 PIN |
| `policy_version` | 当前策略版本，便于回放时知道按哪套规则执行 |

## 3. 还有哪些事件

| `event` | 什么时候写 |
| --- | --- |
| `task_start` | 任务开始，带任务卡快照 |
| `task_end` | 任务结束，带步数、模型调用数、费用估算、停止原因 |
| `tool_call` | 每次工具调用（包括被守卫层拒绝的） |
| `approval` | 人工批准/拒绝，带动作列表与签名凭证 |
| `emergency_stop` | 急停触发/解除 |
| `budget_stop` | 预算超限自动停止 |
| `rollback` | 整批回滚，带恢复/失败/不可逆数量 |

## 4. 回放视图

左侧栏「批次与回滚」→ 每个批次展开「查看回放」：

```text
1. 任务开始：发票归档
2. 写入：D:\归档\2026\a.txt（覆盖）
3. 移动：D:\下载\b.pdf -> D:\归档\2026\b.pdf
4. 删除空目录：D:\下载\临时
5. 回滚：恢复 3 / 失败 0 / 不可逆 0
```

它和审计日志的分工：

- **批次回放**：看“这次任务改了哪些文件”，面向恢复；
- **审计日志**：看“谁批准了什么、策略版本是什么”，面向追责与排障。

## 5. 新增的审计能力

- `log_tool_call` 新增 `batch_id / task_id / step_no / reversibility / approver / approval_token / trace_id`；
- 新增 `log_task_start` / `log_task_end` / `log_approval` / `log_guard_event`；
- 工具挂起等待确认时记 `status=interrupt`，不再把 `Command` 对象误记成成功结果；
- 守卫层拒绝也会记一条 `status=error` 的工具调用，能看出“它试图做什么、被哪条规则拦住”。

## 7. 边界

1. **不是 WORM**：追加写 + 本地 JSONL，防误改但不防同用户恶意程序；有合规要求时再上 WORM/对象锁。
2. **不记录 PIN**：只记录 HMAC 凭证；PIN 明文从不落盘。
3. **日志含用户内容**：参数和结果摘要仍可能包含路径、文件名、命令；需要按保留期清理。
4. **没有独立回放播放器**：当前用批次列表 + `st.text` 展示；足够排障，不是时间轴 UI。
5. **没有外部 SIEM**：日志在本机，备份靠用户自己复制 `logs/` 与 `.agent_state/`。

## 8. 一句话记住

**一条轨迹要能回答：做了什么、谁批的、哪条策略允许的。做不到这三问，就不叫审计。**
