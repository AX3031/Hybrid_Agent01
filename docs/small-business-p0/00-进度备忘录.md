```text
  ▼

  │ guard_model：预算/急停短路
  │ monitor_tool：审计 + 工具失败计数
  │ guard_preflight：停止/只读/任务卡/预算（人工确认前）
  │ HumanInTheLoop：人工确认
  │ guard_execute：再检查 + PIN 验签 + 计步（人工确认后）
  │ verification：任务结束核对机器判据；未配置时 not_required
  ▼
agent/guard/
  ├── task_card.py   任务卡结构、快速卡、可选机器判据、技能参考
  ├── criteria.py    机器判据解析与执行
  ├── scope.py       回滚边界
  ├── policy.py      只读 / 任务卡范围 / R0–R3 分级
  ├── state.py       任务运行时、预算、急停、会话快照、审批上下文
  ├── journal.py     批次日志与整批回滚
  ├── lock.py        单任务文件锁
  ├── approval.py    PIN 哈希、签名凭证、审批目录保护

agent/skill_library.py  本地任务技能库：步骤/截图/复用参考
```

## 7. 当前风险提醒

1. **PIN 不是攻击隔离**：同一 Windows 用户下的恶意程序仍可读进程内存或记录键盘；它只防误触与“模型自己点确认”。
2. **批次日志不是不可篡改审计**：它在 `.agent_state/`，工具不能写，但同用户的其他程序可以改；要更强保证需 WORM / 独立主机。
3. **永久删除无法回滚**：批次回滚会明确报“不可逆”，不会假装恢复。
4. **费用上限是估算**：只有供应商返回 `usage_metadata` 时才计费，否则只记录调用次数。
5. **单任务锁是单机文件锁**：只对同一台机器、同一个状态目录生效；不是分布式锁。
6. **批次只覆盖文件类写操作**：`run_command` 内部修改的文件、`open_path` 与 `computer_use` 的应用内状态不在回滚范围。
